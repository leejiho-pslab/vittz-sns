> 순서대로 진행하면 됩니다. 각 단계마다 **열 링크**와 **복사해서 넣을 값**을 코드 블록으로
> 표시했습니다. 발급 화면이 헷갈리면 **화면 캡처를 보내주세요** — 어디를 누를지 짚어드립니다.
> 모든 키·토큰은 GitHub **Secrets에만** 넣습니다 (코드·채팅에 붙여넣기 금지).

- Secrets 등록: https://github.com/leejiho-pslab/vittz-sns/settings/secrets/actions → `New repository secret`
- Variables 등록: https://github.com/leejiho-pslab/vittz-sns/settings/variables/actions → `New repository variable`

## STEP 0. 새 저장소 만들기 — 대시보드 404 해결 (지금 바로, 1분)

1. 열기: https://github.com/new
2. 아래대로 입력 후 `Create repository`:
```
Repository name : vittz-sns
공개 설정       : Public   (무료 Pages 필수 — 시크릿은 공개돼도 노출되지 않음)
README/기타 체크 : 모두 해제 (빈 저장소)
```
3. 만들고 나서 클로드 채팅에 이렇게 입력:
```
add repo leejiho-pslab/vittz-sns
```
→ 준비된 구성이 자동 푸시되고 대시보드가 https://leejiho-pslab.github.io/vittz-sns/ 로 열립니다.

## STEP 1. 네이버 검색광고 API — 키워드 실측 월간검색수 ✅ 연결 완료 (2026-08-05)

키워드 도구 화면과 **동일한 데이터**를 API로 받아 대시보드 '📊 실측 월간검색수'와
리서치 탭 '🗂 카테고리별 핵심 키워드 검색량'을 채웁니다.

**운영자 지시로 API 자격 증명이 고정값으로 배선되었습니다** — `data/naver-ad-credentials.json`
(계정: withit · CUSTOMER_ID 3425852). GitHub Secrets 등록이 더 이상 필요 없으며,
키를 재발급하면 이 JSON 한 파일만 갱신하면 됩니다. (환경변수 NAVER_AD_*가 있으면 그쪽이 우선)

4. 실행: https://github.com/leejiho-pslab/vittz-sns/actions → `vittz keyword volumes (키워드 도구 실측 수집)` → `Run workflow`
   (이후 매월 1일 자동 갱신)

## STEP 2. 텔레그램 알림 (권장 — 발행 성공/실패·토큰 경보 푸시)

1. 열기: https://t.me/BotFather → 채팅에 입력:
```
/newbot
```
   → 봇 이름/아이디 정한 뒤 나오는 **토큰** 복사
2. 만든 봇과 대화 1회 시작(아무 메시지) 후, 브라우저에서 (토큰 부분 교체):
```
https://api.telegram.org/bot<봇토큰>/getUpdates
```
   → 응답의 `"chat":{"id":숫자}` 가 CHAT_ID
3. Secrets 2개 등록:
```
TELEGRAM_BOT_TOKEN
```
```
TELEGRAM_CHAT_ID
```

## STEP 3. AI 글 생성 (권장)

1. 열기: https://console.anthropic.com/settings/keys → `Create Key` → 복사
2. Secrets 등록:

# 계정 연결 (맨 마지막 단계 — 8월 가동 직전)

## STEP 4. 인스타그램 + 스레드 (@vittz_official)

준비: 인스타그램이 **프로페셔널(비즈니스) 계정**이고 **페이스북 페이지와 연결**되어 있어야 함.

1. 앱 만들기: https://developers.facebook.com/apps → `Create App` (Business 유형)
2. 제품 추가: Instagram Graph API (+ Threads API)
3. 그래프 API 탐색기(https://developers.facebook.com/tools/explorer)에서 권한
   `instagram_basic, instagram_content_publish, pages_show_list` 로 토큰 발급 →
   **장기 토큰**으로 교환
4. Secrets 4개 등록:
```
PSLAB_INSTAGRAM_ACCESS_TOKEN
```
```
PSLAB_INSTAGRAM_IG_USER_ID
```
```
PSLAB_THREADS_ACCESS_TOKEN
```
```
PSLAB_THREADS_THREADS_USER_ID
```
   - IG_USER_ID: 탐색기에서 `me/accounts` → 페이지 선택 → `?fields=instagram_business_account`
   - 참고: 게시물 공개 여부는 계정 설정을 따름 — 앱에서 계정이 **공개**인지 확인

## STEP 5. 유튜브 쇼츠 자동 업로드

1. 프로젝트: https://console.cloud.google.com → 새 프로젝트 → **YouTube Data API v3** 사용 설정
2. OAuth 클라이언트: API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID(웹) 생성 —
   승인된 리디렉션 URI에 추가:
```
https://developers.google.com/oauthplayground
```
3. 토큰: https://developers.google.com/oauthplayground → ⚙️에서 `Use your own OAuth credentials`
   체크 후 클라이언트ID/시크릿 입력 → 스코프 입력:
```
https://www.googleapis.com/auth/youtube.upload
```
   → 인증 → `Exchange authorization code for tokens` → **Refresh token** 복사
4. Secrets 4개 등록:
```
PSLAB_YOUTUBE_CLIENT_ID
```
```
PSLAB_YOUTUBE_CLIENT_SECRET
```
```
PSLAB_YOUTUBE_REFRESH_TOKEN
```
```
PSLAB_YOUTUBE_CHANNEL_ID
```
   - CHANNEL_ID 값:
```
UCqfOTULeIeIurfRY-DXEoyw
```
   - ⚠️ 앱이 "테스트" 상태면 refresh token이 **7일마다 만료** → OAuth Playground에서 재발급.
     완전 무인은 앱 게시(검수) 필요. 업로드 공개범위 기본값은 **전체 공개**입니다.

## STEP 7. 네이버 블로그 — 발급할 것 없음

공식 발행 API가 없어 **수동(복붙) 채널**입니다. 발행일에 대시보드 네이버 블로그 탭에서
`본문 복사` + `이미지 다운로드` 버튼으로 5분이면 게시됩니다.

## 마지막 스위치 (모든 연결 후)

1. Variables 등록 — 실발행 ON:
```
이름: PSLAB_DRY_RUN
값  : false
```
2. Pages 확인: https://github.com/leejiho-pslab/vittz-sns/settings/pages → Source가
   **GitHub Actions** 인지 확인
3. Actions → `vittz cron (무인 루프)` → `Run workflow` 수동 실행 → 대시보드 체크리스트
   완료·첫 발행·텔레그램 알림 확인

- 각 채널 탭 상단 **수정요청 게시판**: 요청 작성 → 처리 상태 자동 표시
